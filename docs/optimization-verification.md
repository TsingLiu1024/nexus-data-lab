# v1.1 优化验证记录

2026-10-17。Windows / Node.js 24.15.0 / Edge；GitHub CI 使用 Ubuntu / Chromium。

## 优化交付

1. 数值列按数值比较等于，文本编号维持文本语义。
2. 数值趋势横轴排序与相邻区间合并；等价数值、日期按实际值分组，文本标识符不合并。
3. GB18030 文件按原始字节执行 10 MiB 限制，保持 50,000 行和 100 列上限。
4. 常驻 Worker 持有原始数据，分页只返回 20 行；缓存筛选、画像、排序及图表；150ms 搜索延迟；隔离过期响应。
5. Windows 一键启动，锁定依赖及源码指纹检查，服务就绪后打开 Edge。已有最新服务复用；运行中实例过期时明确要求先停止并重启，避免打开旧构建或擅自终止已有服务。
6. 主动保存、恢复与删除 IndexedDB 存档，保留数据和分析状态；数据与元信息同一事务写入。存储不可用、类型无效或克隆失败明确报告，原存档保留。
7. 导入预览、分隔符、日期格式和逐列类型设置；更新解析配置必须重做预览，确认或取消行为经过浏览器验证。

## 验证结果

- 数据/分析引擎/存档：40 项单元测试通过。
- 启动器：2 项测试通过，包含源码变化后禁止复用旧构建。
- 浏览器：13 项操作测试通过，覆盖此前功能、配置导入、取消/失败保护、存档跨刷新及大文件。
- 50,000 行浏览器检查：真实 Worker；四个并行浏览器任务下，计算阶段 25ms 计时器运行 92 次，观察到最大主线程任务 201ms，低于回归阈值 1000ms。此结果针对本机及该数据样本，不是所有设备的性能保证。
- TypeScript 与生产构建通过；依赖审计 0 个已知漏洞。
- 最新锁文件 `npm ci --dry-run --ignore-scripts` 通过。
- 生产预览：无运行时异常、无外部数据请求；桌面、390px 手机及配置导入截图已检查。
- 启动器首次安装、生产构建、已有服务复用与运行中过期提示均实测。

## 独立复核

- 相同日期/数值的不同文本表示创建重复图表分组：使用列类型规范化内部键，展示与导出仍保留原值。
- 已有服务绕过更新检查：复用前检查依赖、源码与构建状态，过期实例提示停止并重启。
