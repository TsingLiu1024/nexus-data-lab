# NEXUS Data Lab — 设计

2026-10-17。用户选择 CSV 数据分析台，深色科技风，要求自动完成并推送 GitHub。

## 目标
提供开箱即用的中文数据工作台：浏览器本地解析 CSV/TSV，导入、搜索、筛选、排序、统计、图表及导出。初次打开加载明确标识的合成演示数据。无需账号、后端或付费 API。

## 架构与数据
React + TypeScript + Vite；Papa Parse 解析分隔文本；Recharts 绘图；Lucide 图标。原始值保留为字符串；独立列 key 防止重复列名覆盖，数字推断排除带前导零的编号。支持 UTF-8 / GB18030 和自动分隔符。上限 10 MiB、50,000 数据行、100 列；超限拒绝且保留之前的数据集。

所有导入内容仅保存在当前页面内存，不上传、不写 localStorage。过滤后的同一行集供统计、图表、预览和导出使用。数值统计忽略缺失值；空值不计作零。图表支持分组求和、均值和计数，分类超限合并其他且保留总量。日期轴按日期排序。CSV 导出添加 UTF-8 BOM 并防公式执行；JSON 使用唯一列名。

## 界面
炭黑侧栏、深蓝画布、青色高亮与少量紫色辅助。桌面包含工作区导航、数据集卡片、四张统计卡、趋势图与分类分布、可分页表格；手机堆叠布局。三个视图：分析概览、数据表格、字段分析。可选图表维度、指标、聚合方式，切换折线/柱状。导入对话框支持选择和拖放文件、编码选择。错误、空数据、无数值列和筛选零结果有明确反馈。

## 验收
真实 CSV 引号、BOM、换行、空值、重复表头、畸形行、中文编码、前导零、数值排序、组合筛选和导出有单元测试。浏览器测试验证导入→筛选→图表→导出、恢复演示、无数值列、错误恢复、桌面/移动端溢出及键盘操作。GitHub CI 安装锁定依赖、类型检查、测试与生产构建；可手动运行 Pages 发布工作流（需仓库支持 Pages）。新仓库默认私有。
