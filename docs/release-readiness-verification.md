## 独立复核与修复

独立只读复核提出两项 P2，已通过先失败后通过的回归修复：

- 数值 X 刻度沿用整数紧凑格式时，0.1 / 0.2 / 0.3 均显示为 0。改为保留实际数值刻度，浏览器验证正小数、负小数及 1e-8 级数值。
- Node 测试超时不会自动中断挂起的子进程等待。增加主动拒绝的退出时限、清理时限和 HTTP 超时；模拟延迟退出验证 finally 及时执行。Linux 子进程使用独立进程组，清理仅针对该组；Windows 仅针对本测试创建的进程树。

修复后重新运行全部单元、启动器、浏览器测试与构建；生产预览加载已打包 Worker，真实数值间距比 99，运行时错误及外部请求均为 0。
