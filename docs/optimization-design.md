# NEXUS Data Lab 优化设计

用户授权：按已评估的七项优先级全部优化，沿用全自动开发、验证和 GitHub 推送。

## 按优先级交付

1. 数值列等于比较采用解析后的数值；文本编号仍采用文本比较。
2. 趋势图数值维度按数值排序，相邻数值区间合并；日期按时间排序；环图仍按记录数排序。
3. 本地文件上限统一按原始 ArrayBuffer 字节计算，避免 GB18030 转 UTF-8 后被误判。
4. 常驻 Web Worker 持有原始数据。主页面仅接收分页记录、统计和聚合结果；缓存复用筛选结果，排序/翻页不重算画像；搜索延迟 150ms，过期响应不得覆盖新状态。
5. Windows `start.cmd` 检查 Node、安装锁定依赖、按源文件指纹构建，固定使用 4173 端口，并在用户运行脚本时打开 Edge；复用已有本项目服务，其他服务占用端口则报错。`--no-browser` 用于自动验证。
6. 用户点击保存后，将数据、搜索/筛选/排序、图表、视图、页码写入本机 IndexedDB 单个工作区存档；启动时提示可恢复，不自动加载个人数据。支持恢复、覆盖保存与删除，失败明确提示。
7. 导入先预览再确认。允许 UTF-8/GB18030、自动/逗号/分号/Tab/竖线分隔符、ISO/年-月-日斜线/日-月-年斜线/月-日-年斜线日期格式和每列自动/文本/数值/日期类型。手动类型遇到非法值时报错；原始值保留；取消或失败不替换现有数据。

## 边界与验收

无后端、账号、遥测或上传。保存仅在用户主动点击后发生；存档与浏览器来源/端口绑定。保留 10 MiB / 50,000 行 / 100 列限制。数值仍使用 JavaScript 浮点数，长整数保留文本。Worker 生成全部匹配记录的导出文件。

纯数据、查询缓存、存档事务有单元测试。浏览器验证真实 Worker、导入配置、存档跨刷新、数值排序/筛选、过期请求、手机布局与 50,000 行响应性。启动器不打开浏览器地验证真实子进程。最后独立复核、构建、CI、推送并核对远端提交。
